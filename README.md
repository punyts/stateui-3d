# @punyts/stateui-3d

Draws StateUI 3D scenes (`scene3d` and its nodes) with three.js. The StateUI runtime loads it as a second script, only for apps that use a scene.

The package scaffold, build and tests arrive with story G3.2 of the graphics epic 3 (`knowledge-base/design/stateui-graphics-epic-3-3d-package.md` in ai-minion).
