# Changelog

## Unreleased
- **Renderer core: camera, lights, meshes, materials, background** (G3.5 of the graphics epic 3): `createScene3d` draws a scene from the plain node tree and follows changes on demand. New modules: `diff.ts` (`diffTrees`, `flattenTree`, `changedProperties`, `sameValue`), `scene.ts` (`SceneGraph`: one three.js object per node by path, changed property by property; a node of another component, or a `light` or `camera` of another `kind`, is made again), `cameras.ts` (`activeCamera`: the first `camera` with `active: true`, else the first; `frameBounds` for the default camera that frames what is drawn; `orthographicHeight`), `geometries.ts` (`box`, `sphere`, `cylinder`, `cone`, `plane`, `torus`, `capsule` with defaults about one unit across, sizes clamped to 0..10,000, `segments` to 3..128), `materials.ts` (`MeshStandardMaterial`: `color` white by default, `metalness` 0, `roughness` 1, `opacity`, `emissive`; CSS colours of any form converted), `renderer.ts` (antialiased `WebGLRenderer` with alpha, pixel ratio at most 2, sized from a `ResizeObserver` entry with `setSize(w, h, false)`; `Scene3dError` `no_webgl` and `isScene3dError`). Lights: `ambient`, `directional` (default), `point`, `spot`, `intensity` times π (`LIGHT_SCALE`), point and spot without decay. `update(tree, settings?)` takes the scene's own `Scene3dSettings` (`background`, unset is transparent; `ambient`, an ambient light at 0.4 while `environment` is not `none`). Colours go through the new `resolveColor` option (`ColorResolver`); without it only literals resolve. Every node honours `visible` and the shared `hidden`; `model` is an empty group until G3.7b. Render on demand: one `requestAnimationFrame` per batch of changes, a resize or a restored context, none at rest; `drawn()` resolves after that frame (at once when none waits). The G3.2 unlit unit box is gone (its tests in `src/scene3d.browser.test.ts` changed with it). The chunk is 141,769 bytes gzipped (from 135,135). Tests: `src/diff.test.ts`, `src/cameras.test.ts`, `src/geometries.test.ts`, `src/scene.test.ts` (Node), `test/render.browser.test.ts` (pixels within 12 per channel: a lit box on its background, colour change and removal, lights, tokens, cameras, each geometry, frames at rest, no WebGL).
- **Package scaffold, build and chunk** (G3.2 of the graphics epic 3): the package `@punyts/stateui-3d` 0.1.0, with the build and test shape of the other libraries (`tsconfig.build.json`, `tsconfig.test.json`, `vitest.config.ts`, `vitest.browser.config.ts`). `three` 0.187.0 is pinned exactly with `@types/three` 0.187.0 (G3.1). Exports `.` (the typed API) and `./runtime-chunk/*` (`dist/runtime-chunk/`). The typed API: `createScene3d(host, options)` gives a `Scene3d` with `update(tree)`, `hit`, `boundsOf`, `elementOf`, `setReducedMotion`, `reducedMotion`, `drawn` and `dispose` (the names of the 2D `DrawingRenderer`), over a `Scene3dTree` (`NODE3D_KINDS`, `isNode3dKind`); the first renderer draws a `mesh` as an unlit box and places `group3d` children, the rest comes with G3.5. `runtime-chunk/build.ts` (`buildRuntimeChunk`, `npm run build:runtime-chunk`) bundles `src/chunk.ts` into one minified `iife`, `dist/runtime-chunk/<hash>.js` (sha256, the first 16 hex characters, as the runtime bundle) and `manifest.json` `{ hash, script }`, removing only its own earlier output. The chunk sets the one global `__stateui3d` (`{ version, createScene3d }`, `GLOBAL_NAME`, `Stateui3dGlobal`) and removes the `window.__THREE__` three.js sets unless the page had one. Tests: `runtime-chunk/build.test.ts` (hashing, own output only, one file, a gzip gate 15% above G3.1's 167,830 bytes), `test/package.test.ts` (no `@punyts/stateui-*` runtime dependency, `three` pinned with its types, the version), `src/scene3d.browser.test.ts` and `test/chunk.browser.test.ts` (only `__stateui3d` is added to a page).
